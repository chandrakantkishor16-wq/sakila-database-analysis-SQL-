## 📌 Project Overview
This project explores the canonical Sakila database, which simulates a complete DVD rental business ecosystem. Using SQL for data extraction and manipulation, I analyzed over 16,000 rental transactions across 16 interconnected tables to uncover business-critical insights regarding inventory performance, customer behavior, and revenue generation.

## 💡 Key Business Questions Answered
1. **Inventory:** Which movie categories drive the highest revenue and rental rates?
2. **Customers:** Who are our most loyal customers, and what is their lifetime value (LTV)?
3. **Operations:** How do the two store locations compare in terms of transaction volume and late fees?

## 📂 Repository Contents
* `analysis_queries.sql`: Contains the SQL scripts used to extract and aggregate the data.
* `Sakila_Presentation.pdf`: The final slide deck visualizing the findings.

## 🚀 Key Insights & Recommendations
* **Stock Optimization:** Sports and Sci-Fi titles yield the highest return; inventory should be increased for these categories.
* **Customer Retention:** The top 10% of customers drive a disproportionate amount of revenue. Implementing a targeted loyalty program for the top 50 users is highly recommended.
